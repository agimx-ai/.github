# AGIMX AI

**Practical agentic AI for engineering and real-world work.**

AGIMX stands for **Agile Implementation, Manufacturing, and X Solutions**. We build reliable AI-agent products, deterministic MCP tools, and industrial automation integrations—starting from the workflows our own engineering teams use.

## Featured product

### [SeedAgent TIA Portal Programming Agent](https://github.com/agimx-ai/seedagent-tia-programming)

SeedAgent lets users work with Siemens TIA Portal in natural language through Tencent WorkBuddy. It can operate TIA Portal on the local computer or on paired engineering workstations and supports TIA Portal V16–V21.

- Create, restore, open, attach to, and manage TIA Portal projects
- Read, generate, compare, import, and export SCL program blocks
- Compile in the actual target TIA Portal installation and return real diagnostics
- Archive projects and, after explicit confirmation, download to PLCSIM Advanced or a physical PLC
- Keep project lifecycle, workstation selection, file transfer, billing, confirmations, and safety boundaries in deterministic product code rather than improvised model behavior

Current public release: **0.9.0**. The product currently focuses on S7-1200, S7-1500, and SCL, with a Chinese-first experience and WorkBuddy as the officially supported AI-agent client.

[Product overview, installation, limitations, and support →](https://github.com/agimx-ai/seedagent-tia-programming)

## What we build

- Product-grade AI agents for engineering and knowledge work
- MCP-based tools that give AI models controlled access to real software and systems
- Industrial automation integrations shaped by actual controls-engineering practice

Our products are not based on asking a model to discover operational APIs through unlimited trial and error. We move repeatable operations, safeguards, and lifecycle rules into deterministic tools, then let the model focus on requirements, design, analysis, and collaboration.

## 主力产品

### [SeedAgent 博途（TIA Portal）编程智能体](https://github.com/agimx-ai/seedagent-tia-programming)

SeedAgent 让用户通过腾讯 WorkBuddy，用自然语言操作本机或已配对工程电脑上的西门子 TIA Portal，当前支持 TIA Portal V16–V21。

- 创建、恢复、打开、挂载和管理博途工程
- 读取、生成、比较、导入和导出 SCL 程序块
- 调用目标电脑上的真实 TIA Portal 编译并返回实际诊断
- 归档工程，并在明确确认后下载到 PLCSIM Advanced 或物理 PLC
- 将项目生命周期、工程机选择、文件传递、收费、确认和安全边界固化在确定性产品代码中，而不是依赖模型临场试错

当前公开版本为 **0.9.0**，主要覆盖 S7-1200、S7-1500 与 SCL，以中文使用体验为主，目前正式适配的 Agent 客户端为 WorkBuddy。

[查看产品介绍、安装方式、能力边界和支持渠道 →](https://github.com/agimx-ai/seedagent-tia-programming)

## 我们在做什么

- 面向工程和知识工作的产品级智能体
- 让 AI 在明确边界内操作真实软件与系统的 MCP 工具
